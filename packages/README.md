# Shared Packages

- `shared-types/`: Shared TypeScript data contracts, interfaces, and enum definitions across web portals and mobile.
- `api-client/`: Type-safe HTTP client wrapping Axios/Fetch for communicating with the FastAPI `/api/v1/` endpoints.
- `validation/`: Common validation rules (phone numbers, Indian vehicle registration formats, pricing limits).
- `design-system/`: Design tokens, UI component library, Tailwind preset, and icon configurations (Lucide React).
