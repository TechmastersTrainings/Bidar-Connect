# Public Web Application (`apps/public-web`)

## Role
Component 1 of the Bidar Connect ecosystem.

## Scope
- Marketing landing pages for the Bidar ⇄ Hyderabad corridor.
- "Find a Ride" and "Offer a Ride" conversion funnels.
- Route details, operating hours, safety guidelines, and how it works.
- Legal documents: Privacy Policy, Terms of Service, Refund Policy, Cookie Notice.
- Dynamic FAQs and contact support forms.

## Technology
- Next.js (App Router)
- React, TypeScript
- Tailwind CSS
- Lucide React
