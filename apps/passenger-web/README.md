# Passenger Web Portal (`apps/passenger-web`)

## Role
Component 2 of the Bidar Connect ecosystem.

## Scope
- Passenger registration and OTP-based authentication.
- Ride discovery engine (origin, destination, date, seats, pickup/drop filters).
- Instant seat checkout and payment handling (company UPI/gateway).
- Booking management (upcoming, completed, cancelled journeys).
- Trip receipts, driver contact disclosure (under privacy controls), emergency contact journey sharing.
- Post-trip driver reviews and dispute/complaint reporting.

## Technology
- Next.js (App Router)
- React, TypeScript, Tailwind CSS
- Lucide React
