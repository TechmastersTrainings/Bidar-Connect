# Driver Web Portal (`apps/driver-web`)

## Role
Component 3 of the Bidar Connect ecosystem.

## Scope
- Driver registration and verification.
- Fleet management: add multiple vehicles, upload RC, insurance, PUC, front/rear/interior photos.
- Driving licence document management and validity tracking.
- Ride publishing (origin, destination, intermediate stops, date, departure time, seat count).
- Admin-enforced fare auto-fill (drivers cannot override pricing).
- Confirmed passenger manifests and journey lifecycle tracking (Start Ride, Record Arrival, Ride Completed).
- Earnings summary, commission breakdown, and payout tracking.

## Technology
- Next.js (App Router)
- React, TypeScript, Tailwind CSS
- Lucide React
