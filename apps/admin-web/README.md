# Admin Web Portal (`apps/admin-web`)

## Role
Component 4 of the Bidar Connect ecosystem.

## Scope
- Central executive dashboard: gross booking value, company commission, active rides, active users.
- User management: passenger and driver compliance audits, account suspension/reactivation.
- Vehicle & document compliance review (RC, Insurance, PUC, Driving Licence).
- Route & pricing management: route stops, per-seat pricing matrices, commission formulas, effective dates.
- Ride and booking monitoring with immutable audit logging.
- Financial management: payment reconciliation, driver payout approvals, dispute resolution, financial ledger export.

## Technology
- Next.js (App Router)
- React, TypeScript, Tailwind CSS
- Lucide React
